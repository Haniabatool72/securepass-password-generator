## 📖 Description

**SecurePass** generates strong, random passwords with a single click. You choose the length and character types, and a live strength meter shows how secure the result is. Passwords are created locally with the browser's cryptographic random number generator (`crypto.getRandomValues`) and are never sent anywhere or stored.

## ✨ Features

- Adjustable password length (6–40 characters)
- Options for uppercase letters, lowercase letters, numbers and symbols
- Guaranteed inclusion of every selected character type
- One-click **Generate Password** and **Copy Password** buttons
- Password strength indicator based on entropy
- Secure randomness using the Web Crypto API
- Fully responsive on mobile and desktop
- Smooth hover effects and subtle animations
- Keyboard accessible, with reduced-motion support

## 🛠️ Technologies Used

- **HTML5** – semantic structure
- **CSS3** – custom properties, Flexbox, transitions and animations
- **JavaScript (ES6+)** – DOM manipulation, Clipboard API and Web Crypto API

## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/securepass.git
   ```
2. Open the project folder and double-click `index.html` (no build step or dependencies needed).
3. Move the slider to choose a password length.
4. Tick the character types you want to include.
5. Click **Generate password**.
6. Click the copy icon to copy it to your clipboard.
